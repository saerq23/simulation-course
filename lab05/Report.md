# Лабораторная работа: Моделирование случайных событий  
## (LCG, настраиваемые вероятности для каждого ответа)

### Цель работы  
Разработать приложения для получения случайных ответов «Да»/«Нет» и «Шар предсказаний» (Magic 8‑Ball) с использованием реализованного вручную генератора случайных чисел (линейный конгруэнтный метод). Обеспечить гибкую настройку вероятностей для каждого возможного ответа во второй части.

### Используемый генератор случайных чисел (ГСЧ)  
В работе применяется **мультипликативный конгруэнтный генератор (LCG)** с параметрами:  
- Модуль \( m = 2^{31} - 1 = 2147483647 \)  
- Множитель \( a = 16807 \)  
- Начальное состояние (seed) задаётся пользователем  

Генератор возвращает равномерно распределённые числа в интервале \([0, 1)\).  
Реализация исключает использование встроенного `random` — все случайные выборки выполняются только через собственный LCG.

### Приложение 1: «Скажи "да" или "нет"»  
При нажатии кнопки генерируется случайное число и сравнивается с заданной вероятностью события «Да» (значение от 0 до 1):  
- Если случайное число < вероятность → ответ **«Да»**  
- Иначе → ответ **«Нет»**  

**Параметры:**  
- Вероятность «Да» можно менять в диапазоне \([0, 1]\) с шагом 0.01 (поле ввода).  
- По умолчанию вероятность = 0.5.  

**Демонстрация:**  
- При вероятности 0 → всегда «Нет»  
- При вероятности 1 → всегда «Да»  
- При вероятности 0.5 → примерно равное количество «Да» и «Нет» при большом числе испытаний.

### Приложение 2: «Шар предсказаний (Magic 8‑Ball)»  
Пользователь задаёт вопрос в текстовом поле. Программа:  
1. **Выбирает конкретный ответ** из полного списка (18 фраз) в соответствии с **индивидуальными весами (вероятностями)**, заданными пользователем для **каждого ответа отдельно**.  
2. Веса нормализуются (сумма становится равной 1), после чего случайный ответ выбирается с полученными вероятностями.  

**Список ответов (18 шт.):**  
- Положительные (9 шт.): «Да», «Бесспорно», «Определённо да», «Предрешено», «Никаких сомнений», «Можешь быть уверен в этом», «Вероятнее всего», «Хорошие перспективы», «Знаки говорят — да».  
- Нейтральные (5 шт.): «Пока не ясно, попробуй снова», «Спроси позже», «Лучше не рассказывать», «Сейчас нельзя предсказать», «Сконцентрируйся и спроси опять».  
- Отрицательные (4 шт.): «Не рассчитывай на это», «Мой ответ — нет», «Весьма сомнительно», «Перспективы не очень хорошие».  

**Параметры (гибкое управление вероятностями):**  
- Для **каждого ответа** предусмотрено отдельное поле ввода веса (вероятности).  
- Кнопка **«Нормализовать вероятности»** приводит сумму весов к 1, сохраняя их пропорции.  
- Кнопка **«Сбросить (равные вероятности)»** делает все ответы равновероятными.  
- **Специальная функция «Уравнять остальные»**:  
  - Пользователь выбирает один ответ из выпадающего списка и задаёт его целевую вероятность (например, 0.4).  
  - Программа автоматически устанавливает для выбранного ответа указанную вероятность, а для всех остальных — равные доли от оставшейся суммы (1 – целевая вероятность).  
  - Это позволяет, например, сделать один ответ в 2 раза вероятнее остальных без ручного расчёта весов.

### Реализация  
- **Графический интерфейс** — `tkinter`.  
- **Собственный LCG** вынесен в отдельный класс `CustomRNG`.  
- **Изменение зерна** (seed) — пользователь может ввести новое значение и нажать «Сбросить ГСЧ», после чего последовательность случайных чисел становится детерминированной и воспроизводимой.  
- **Анимация** при смене ответа (плавное изменение текста, для Magic 8‑Ball — смена цвета в зависимости от типа ответа: зелёный — положительный, оранжевый — нейтральный, красный — отрицательный).
- **Прокрутка** — всё содержимое окна снабжено вертикальной полосой прокрутки, что гарантирует доступ ко всем элементам даже на небольших экранах.  

### Результаты работы  
1. **Приложение «Скажи да/нет»**  
   - Каждое нажатие даёт новый ответ, статистически соответствующий заданной вероятности.  
   - При вероятности 0.5 за 100 нажатий получается около 50 «Да» и 50 «Нет» (при фиксированном зерне последовательность воспроизводима).  

2. **Приложение «Шар предсказаний»**  
   - При равных весах (по умолчанию) все 18 ответов появляются с одинаковой частотой (~5.56%).  
   - Если установить для ответа «Да» вес 0.4, а для остальных нажать «Уравнять остальные», то «Да» будет выпадать с вероятностью 40%, а каждый из оставшихся 17 ответов — с вероятностью \(0.6 / 17 ≈ 3.53\%\).  
   - Изменение зерна позволяет получить другую последовательность ответов при тех же вероятностях.  

3. **Проверка нормализации**  
   - При вводе произвольных положительных чисел (например, 2, 5, 7) и нажатии «Нормализовать вероятности» программа корректно пересчитывает веса так, чтобы их сумма стала равна 1.  

### Вывод  
Разработанные приложения демонстрируют работу собственного линейного конгруэнтного генератора, возможность задания произвольных вероятностей для каждого исхода и удобное управление этими вероятностями через графический интерфейс. Реализованные функции («уравнять остальные», нормализация, сброс к равным вероятностям) делают программу гибким инструментом для моделирования случайных событий с неоднородными распределениями.
