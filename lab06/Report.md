# Отчёт по лабораторной работе №6

## Имитационное моделирование дискретной и нормальной случайных величин

## Цель

Реализовать в графическом интерфейсе:

- генерацию дискретной случайной величины по заданному ряду распределения;
- расчёт эмпирических вероятностей, выборочного среднего, дисперсии и относительных погрешностей;
- вычисление статистики $\chi^2$ и проверку гипотезы при $N = 10, 100, 1000, 10000$;
- генерацию нормальной случайной величины и построение гистограммы.

## 1. Теоретическая часть  

**Моделирование ДСВ — метод обратной функции распределения.** Пусть ДСВ X задана рядом $P(X = x_i) = p_i$, $\sum p_i = 1$. Генерируется $\alpha \sim U(0,1)$, находится индекс $k$ такой, что $\sum_{i<k} p_i \le \alpha < \sum_{i \le k} p_i$, и выход полагается равным $x_k$. Вероятность выбрать $x_k$ равна длине $k$-го интервала, то есть $p_k$.

**Моделирование нормальной СВ — метод Бокса–Мюллера.** Для независимых $U_1, U_2 \sim U(0,1)$:
$$
Z_0 = \sqrt{-2\ln U_1}\cos(2\pi U_2), \qquad Z_1 = \sqrt{-2\ln U_1}\sin(2\pi U_2)
$$
— независимые $\mathcal{N}(0,1)$. Далее $X = \mu + \sigma Z \sim \mathcal{N}(\mu, \sigma^2)$.

**Выборочные характеристики.** Эмпирические вероятности $p_i^* = n_i/N$; среднее $\bar{x} = \frac{1}{N}\sum x_j$; дисперсия $s^2 = \frac{1}{N}\sum (x_j - \bar{x})^2$ (смещённая оценка, при больших $N$ разница с несмещённой пренебрежима); относительная погрешность $\delta_\theta = |\hat{\theta} - \theta|/|\theta| \cdot 100\%$.

**Критерий χ² Пирсона.** Статистика
$$
\chi^2_{\text{набл}} = \sum_{i=1}^{k} \frac{(n_i - N p_i)^2}{N p_i}
$$
при верной $H_0$ асимптотически имеет распределение χ² с $df = k - 1 - r$, где $r$ — число параметров, оценённых по выборке. Для ДСВ вероятности заданы, $r=0$, $df = k-1$. Для нормальной — параметры $\mu, \sigma$ рассматриваются как оцениваемые, $r=2$, $df = k-3$. При $\alpha = 0.05$: $\chi^2_{\text{набл}} \le \chi^2_{\text{крит}}(df)$ — $H_0$ принимается, иначе отвергается. **Условие применимости:** все $N p_i \ge 5$; иначе соседние категории объединяются, $k$ и $df$ пересчитываются по числу категорий после объединения. Если после объединения $df \le 0$ — критерий **неприменим**.

**Генератор.** Собственный LCG: $X_{n+1} = (16807 \cdot X_n) \bmod (2^{31}-1)$, $R = X/m$ (Парк–Миллер). Seed задаётся пользователем → воспроизводимость.

## 2. Реализация

Python + `tkinter`/`ttk`, графики — `matplotlib`. Две вкладки: «Дискретная СВ» и «Нормальная СВ». На каждой — поля ввода (`seed` + параметры), кнопки $N = 10, 100, 1000, 10000$ и «Прогнать все N», таблица результатов, график и текстовое резюме.

Ключевые особенности:
- собственный LCG с seed;
- метод обратной функции для ДСВ, Бокс–Мюллер — для нормальной;
- **объединение редких бинов** до $N p_i \ge 5$ перед χ²;
- при невыполнении условий применимости выводится «критерий неприменим»;
- сводная таблица по 4 объёмам выборки.

## 3. Вывод

Реализованы генераторы ДСВ (обратная функция распределения) и нормальной СВ (Бокс–Мюллер) на основе собственного LCG с воспроизводимым seed; проведена полная статистическая обработка выборок и проверка согласия по критерию χ² Пирсона.

С ростом $N$ эмпирические вероятности, среднее и дисперсия сходятся к теоретическим по закону больших чисел; относительные погрешности убывают как $O(1/\sqrt{N})$ — от единиц процентов при $N=10$ до долей процента при $N=10000$. При $N=10$ критерий χ² неприменим (ожидаемые частоты $< 5$); при $N \ge 100$ гипотеза о согласии с заданным распределением принимается при $\alpha = 0.05$. Корректный учёт числа оцениваемых параметров даёт $df = k-1$ для ДСВ и $df = k-3$ для нормальной СВ.
