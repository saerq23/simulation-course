# Отчёт по лабораторной работе №6

## Имитационное моделирование дискретной и нормальной случайных величин

## Цель

Реализовать в графическом интерфейсе:

- генерацию дискретной случайной величины по заданному ряду распределения;
- расчёт эмпирических вероятностей, выборочного среднего, дисперсии и относительных погрешностей;
- вычисление статистики $\chi^2$ и проверку гипотезы при $N = 10, 100, 1000, 10000$;
- генерацию нормальной случайной величины и построение гистограммы.

## Теоретическая часть  

#### Моделирование дискретных случайных величин  
Для генерации значений ДСВ, заданной рядом распределения  

P(X = x_i) = p_i, \quad i = 1, 2, ..., m,

используется **метод обратного преобразования**. Пусть \(F(x)\) – функция распределения. Тогда алгоритм состоит в следующем:  
1. Генерируется равномерно распределённое на \([0,1)\) случайное число alpha.  
2. Находится такое \(k\), что  
   sum_{i=1}^{k-1} p_i \le \alpha < \sum_{i=1}^{k} p_i.
3. Выходное значение принимается равным \(x_k\).

Данный метод универсален и легко реализуется для любого конечного набора значений.

#### Моделирование нормальной случайной величины  
Для получения нормально распределённых чисел использовался **метод Бокса–Мюллера**. Если \(U_1\) и \(U_2\) – независимые равномерно распределённые на \((0,1)\) случайные величины, то величины  

Z_0 = \sqrt{-2\ln U_1} \cos(2\pi U_2), \quad
Z_1 = \sqrt{-2\ln U_1} \sin(2\pi U_2)

являются независимыми и имеют стандартное нормальное распределение mathcal{N}(0,1). Для получения величины с параметрами mu и sigma^2 применяется линейное преобразование:  

X = mu + sigma Z.

#### Статистическая обработка результатов  
Для выборки объёма \(N\) вычисляются:  
- **Эмпирические частоты** \(n_i\) и относительные частоты \(p_i^* = n_i / N\).  
- **Выборочное среднее**:  
  bar{x} = \frac{1}{N}\sum_{j=1}^N x_j.
- **Выборочная дисперсия** (смещённая оценка для ДСВ, несмещённая – для нормальной):  
  s^2 = frac{1}{N}sum_{j=1}^N (x_j - \bar{x})^2. 
- **Относительная погрешность** оценки параметра theta:  
  delta_theta = frac{|hat{theta} - theta|}{|theta|} cdot 100%.

#### Критерий согласия χ² Пирсона  
Для проверки гипотезы \(H_0\): «выборка извлечена из распределения с заданными вероятностями \(p_i\)» вычисляется статистика  

\chi^2 = \sum_{i=1}^{k} \frac{(n_i - N p_i)^2}{N p_i},

где \(k\) – число интервалов (или значений). При справедливости \(H_0\) эта статистика асимптотически имеет распределение χ² с числом степеней свободы \(df = k - 1 - r\), где \(r\) – число параметров распределения, оцененных по выборке. Для дискретного распределения с известными теоретическими вероятностями \(r = 0\), для нормального с заданными \(\mu\) и \(\sigma\) также \(r = 0\) (в работе параметры считаются заданными, а не оцененными). Критическое значение \(\chi^2_{\text{крит}}\) выбирается для уровня значимости \(\alpha = 0.05\). Если \(\chi^2 > \chi^2_{\text{крит}}\), гипотеза отвергается.

#### Генератор псевдослучайных чисел  
Вместо стандартного датчика языка программирования реализован собственный **линейный конгруэнтный генератор (LCG)**:  

\[
X_{n+1} = (a \cdot X_n) \bmod m, \quad R_{n+1} = \frac{X_{n+1}}{m},
\]

с параметрами \(a = 16807\), \(m = 2147483647\) (простое число Мерсенна), предложенными Парком и Миллером. Начальное состояние задаётся пользователем.

## Реализация

- Использован собственный генератор псевдослучайных чисел (LCG) с задаваемым seed.
- Для дискретной величины реализован метод обратной функции распределения (по накопленным вероятностям).
- Для нормальной величины применено преобразование Бокса-Мюллера.
- Для обеих моделей вычисляются выборочные характеристики и статистика $\chi^2$; результаты выводятся в интерфейсе.

## Вывод

Приложение моделирует дискретные и нормальные случайные величины. При увеличении объёма выборки эмпирические вероятности, среднее и дисперсия стабилизируются и приближаются к теоретическим значениям, что подтверждает адекватность реализованных генераторов и расчётов.
