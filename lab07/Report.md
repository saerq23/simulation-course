# Отчёт 
В рамках данной лабораторной работы была разработана программа для имитационного моделирования смены погоды с использованием аппарата цепей Маркова с непрерывным временем.

### Реализованный функционал

#### 1. Построение модели
- **Состояния системы:** 1 – Ясно, 2 – Облачно, 3 – Пасмурно.
- **Матрица интенсивностей переходов:** в графическом интерфейсе пользователь вводит шесть внедиагональных элементов \( q_{ij} \) (\(i \neq j\)).  
- **Интенсивности выхода** \( \lambda_i \) вычисляются автоматически как сумма интенсивностей переходов из состояния \(i\):  
  \[
  \lambda_i = \sum_{j \neq i} q_{ij}.
  \]
- **Параметры симуляции:** задаётся общее время моделирования (в днях) и начальное состояние.

#### 2. Проведение симуляции
- **Мгновенный режим («Запустить мгновенно»)** – моделирование выполняется в отдельном потоке, не блокируя интерфейс. Расчёт ведётся до заданного времени с использованием экспоненциального распределения длительностей пребывания в состояниях. По завершении автоматически обновляются статистические показатели и график.
- **Анимация («Анимация (1 день = 1с)»)** – событийный алгоритм исполняется пошагово с реальной задержкой: каждая единица модельного времени (1 день) соответствует ~1 секунде. В процессе анимации плавно обновляются панель текущей погоды, счётчик времени и таблица статистики.
- **Управление процессом:**
  - Кнопка **«Сброс»** корректно останавливает текущую симуляцию (в т.ч. отменяет запланированные вызовы `after`), очищает накопленные данные и возвращает интерфейс к начальным значениям.
  - Реализована защита от ошибок при закрытии окна: все фоновые потоки и таймеры завершаются в методе `on_closing`.

#### 3. Статистическая обработка
- **Теоретическое стационарное распределение** \(\pi\) находится аналитически из решения системы линейных уравнений:
  \[
  \pi Q = 0, \quad \sum_{i=1}^{3} \pi_i = 1.
  \]
  В программе используется `numpy.linalg.solve` с подстановкой условия нормировки.
- **Эмпирические вероятности** вычисляются как отношение суммарного времени, проведённого в каждом состоянии \(T_i\), к общему времени моделирования \(T_{\max}\):
  \[
  P_i^{\text{эмп}} = \frac{T_i}{T_{\max}}.
  \]
- **Таблица сравнения** отображает для каждого состояния: абсолютное время пребывания (дни), эмпирическую вероятность, теоретическую вероятность и абсолютную погрешность \(|P_i^{\text{эмп}} - \pi_i|\).

#### 4. Визуализация и экспорт данных
- **Графическое представление:** на встроенной панели `matplotlib` строится групповая столбчатая диаграмма, где для каждого состояния сопоставлены эмпирическая и теоретическая вероятности (синий и красный столбцы соответственно).
- **Экспорт результатов:** при нажатии кнопки **«Скачать CSV»** открывается диалог сохранения файла. В файл записывается детальная история смены состояний: для каждого интервала указывается момент окончания (`day_end`), название состояния и длительность пребывания (`duration`). Формат кодировки — UTF-8 с BOM для корректного отображения в русскоязычных табличных редакторах.
- **Логирование:** все интервалы сохраняются в список `simulation_data`, что позволяет в любой момент выгрузить траекторию даже во время анимации.


## Вывод
Программа полностью соответствует требованиям лабораторной работы: поддерживает гибкую настройку интенсивностей переходов, два режима симуляции, непрерывное сравнение эмпирических данных с теоретическим распределением, наглядную визуализацию и сохранение результатов в CSV-формате. Реализованные меры по управлению потоками и таймерами гарантируют стабильную работу приложения при многократных запусках, сбросах и закрытии окна.
