## Краткий отчет  
**Тема:** Моделирование пуассоновского потока заявок на сервер (GUI)  

### 1. Цель работы  
Разработать приложение с графическим интерфейсом для моделирования пуассоновского потока заявок, визуализировать распределение числа заявок по интервалам и сравнить эмпирические статистики с теоретическими значениями.

### 2. Инструменты и среда  
- Язык: Python 3.  
- Библиотеки: tkinter (GUI), matplotlib (графики), стандартная библиотека (math, random).  

### 3. Интерфейс программы  
Приложение разделено на две части:  
- **Левая панель:** поля ввода параметров (λ, T, длительность симуляции), кнопки «Запустить симуляцию» и «Сброс», теоретическое значение μ = λT.  
- **Правая панель:** сводка результатов (число интервалов, заявки в последнем интервале, среднее, дисперсия), таблица «Число заявок по интервалам», столбчатая диаграмма распределения, текстовый вывод.  

### 4. Метод моделирования  
Генерация заявок осуществляется методом обратного преобразования: интервал между заявками распределён экспоненциально:  
Δt = –ln(1–U) / λ, где U ~ Uniform(0,1).  
Время накапливается; заявка относится к соответствующему интервалу длиной T. Моделирование прекращается при превышении общей длительности. Для каждого интервала подсчитывается количество заявок.

### 5. Пример результатов (при λ = 2, T = 5 с, длительность 60 с)  
После запуска получены (результаты варьируются при каждом запуске):  

| Интервал | Диапазон, с | Заявок |
|----------|--------------|--------|
| 1        | 0.00 – 5.00  | 12     |
| 2        | 5.00 – 10.00 | 8      |
| 3        | 10.00 – 15.00| 11     |
| ...      | ...          | ...    |

- **Среднее число заявок на интервал:** ≈ 10.1  
- **Дисперсия:** ≈ 9.8  
- **Теоретическое значение μ = λT:** 10.0  

Гистограмма распределения показывает пик вблизи 10, что характерно для пуассоновского закона.

### 6. Вывод программы  
Автоматический анализ сравнивает относительные отклонения среднего и дисперсии от μ с порогом 15%:  
«Среднее и дисперсия близки к теоретическому μ = 10.000. Результаты согласуются с пуассоновским характером потока.»

### 7. Заключение  
Разработанное GUI-приложение полностью воспроизводит логику веб-примера и позволяет наглядно исследовать свойства пуассоновского потока. Эмпирические оценки среднего и дисперсии согласуются с теоретическими, подтверждая корректность моделирования. Программа может использоваться для лабораторных и демонстрационных целей.
