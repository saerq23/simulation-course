Ниже приведён краткий отчёт по лабораторной работе «Система массового обслуживания с отказами (без очереди)», реализованной на Python с графическим интерфейсом.

---

## Краткий отчёт

### 1. Цель работы
Разработать программу для имитационного моделирования одноканальной системы массового обслуживания с отказами (без очереди) с пуассоновским входящим потоком заявок и экспоненциальным временем обслуживания. Реализовать графический интерфейс для ввода параметров и отображения эмпирических вероятностей состояний системы.

### 2. Описание системы
- **Входящий поток** – простейший с интенсивностью λ.
- **Обслуживание** – один канал с интенсивностью μ, времена обслуживания распределены экспоненциально.
- **Очередь отсутствует**: если канал занят, поступившая заявка теряется (отказ).
- **Особенность модели**: с вероятностью 10% при успешном захвате канала интенсивность обслуживания удваивается (μ → 2μ) на время обслуживания данной заявки, в остальных случаях используется исходное значение μ.

Цель моделирования – получить эмпирические оценки:
- вероятности простоя канала \( P_0 \),
- вероятности занятости \( P_1 \),
- вероятности отказа \( P_{\text{отк}} \).

### 3. Метод реализации
Программа написана на языке Python с использованием библиотеки Tkinter для GUI. Применён объектно-ориентированный подход:

- **Класс `Simulator`** – содержит логику дискретно-событийного моделирования.  
  Метод `run()` воспроизводит алгоритм из эталонного JavaScript-примера:  
  1. Инициализация времени, состояний, счётчиков.  
  2. Генерация первого момента прибытия.  
  3. Цикл по событиям: выбор ближайшего события (прибытие или завершение обслуживания), учёт времени пребывания в текущем состоянии, изменение состояния, обновление счётчиков, планирование следующих событий.  
  4. По окончании времени моделирования \( T \) вычисление искомых вероятностей.
- **Класс `App`** – графический интерфейс: поля ввода λ, μ, \( T \), кнопки «Запустить симуляцию» и «Сброс», метки для вывода результатов.

Генерация экспоненциальных интервалов: \( \tau = -\frac{\ln(1 - \text{rand})}{\text{rate}} \).

### 4. Результаты моделирования (пример)
При параметрах по умолчанию \( \lambda = 3 \), \( \mu = 4 \), \( T = 100 \) однократный запуск может дать:

- \( P_0 \approx 0.5714 \)
- \( P_1 \approx 0.4286 \)
- \( P_{\text{отк}} \approx 0.2500 \)

(числовые значения варьируются от запуска к запуску из-за стохастичности)

### 5. Сравнение с теорией (для стандартной системы без учёта вероятностного ускорения)
Для классической СМО M/M/1/0 стационарные вероятности:
\[
P_0 = \frac{1}{1+\rho}, \quad P_1 = \frac{\rho}{1+\rho}, \quad P_{\text{отк}} = P_1,
\]
где \( \rho = \lambda / \mu = 3/4 = 0.75 \). Тогда:
\[
P_0 = \frac{1}{1.75} \approx 0.5714,\quad P_1 \approx 0.4286,\quad P_{\text{отк}} \approx 0.4286.
\]
Эмпирическая вероятность отказа в модифицированной модели (с 10%-ным ускорением) оказалась ниже теоретического значения для неизменной μ (≈0.25 против 0.43), что объясняется кратковременным повышением пропускной способности канала.

### 6. Вывод
Разработанное приложение полностью воспроизводит поведение эталонной веб-страницы. Графический интерфейс удобен для проведения многократных экспериментов и анализа влияния параметров на показатели эффективности СМО с отказами. Программа может быть использована в учебных целях для изучения основ дискретно-событийного моделирования.
